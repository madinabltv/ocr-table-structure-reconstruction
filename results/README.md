# Итоговые результаты

В каталоге сохранены только компактные артефакты итогового сравнения:

- `method_summary.csv` — усреднённые показатели по методам;
- `per_document_metrics.csv` — показатели по отдельным документам;
- PNG-файлы — графики качества и времени выполнения.

Обученные модели и полный каталог промежуточных результатов не включены из-за размера. Они создаются заново скриптами из каталога `src/`.
